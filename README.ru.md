# QuietSelection для Windows 11

Приложение для локального чтения выделенного текста, распознавания выбранной области и перевода. Основной код — C#/.NET 10 и WPF. Небольшой модуль C++/WinRT подключает системные речь и OCR.

**Текущая версия — этап разработки, а не выполненное ТЗ.** Подписанный MSIX 0.1.0.21 установлен с собственными средами .NET и Python. Речь поддерживает WinRT, SAPI 5 (RHVoice Elena/SLT), локальные модели Piper Denis/Dmitri/Irina/Ruslan/LJSpeech, пять русских голосов Silero V5.6, восемь английских голосов KittenTTS Mini 0.8, 21 английский профиль Pocket TTS, 28 английских голосов Kokoro INT8 и обычные японские VOICEVOX 四国めたん / 玄野武宏. Английский Silero отклонён после пользовательского прослушивания; его модель удалена из данных приложения и кэша загрузки. Выбранные модели Piper, Silero, Kitten, Pocket, Kokoro и VOICEVOX по умолчанию остаются в памяти; переключатели в разделе «Речь» позволяют их выгрузить. Piper LJSpeech доступен для сравнения; профиль Micro Bella заменяется одноимённым Mini Bella с сохранением скорости. Kitten Micro удалён по результатам прослушивания; Kokoro остаётся доступным для сравнения. Для Kokoro/VOICEVOX подобрано число потоков и добавлена подготовка следующего фрагмента во время чтения; см. [замеры производительности](docs/speech-performance.md). Русский и английский Silero могут совместно использовать один процесс PyTorch. Добавлены Alt+1–4 с цифрами верхнего ряда. Японский → русский использует прямую модель OPUS-MT. Пройдены 55/55 тестов ядра. Замеры памяти голосов и проверки установленного пакета приведены в [состоянии работ](docs/status.md) и [документации голосов](docs/voices.md). Полный сценарий OCR, внешняя совместимость, автозапуск и откат ещё не завершены.

При автоопределении русские, английские и японские вставки внутри предложения читаются выбранными голосами соответствующих включённых языков. Следующий звук готовится во время воспроизведения предыдущего, в том числе при смене движка. Частые короткие вставки с медленной моделью всё ещё могут создавать паузы. Alt+2 и выключенное автоопределение сохраняют один основной голос. В таком режиме русский Silero по-прежнему преобразует латиницу в приблизительное русское произношение с локальным словарём eSpeak. Числа, десятичные дроби, диапазоны и основные единицы измерения нормализуются перед синтезом.

## Сборка и запуск

SDK 10.0.402 находится в `.tools/dotnet`. Используются уже установленные MSVC и Windows SDK 10.0.26100.0. NuGet-источники отключены: сборка не загружает дополнительные пакеты.

```powershell
./scripts/Build.ps1
./scripts/Test-Core.ps1
./scripts/Test-Privacy.ps1
./scripts/Test-WindowsApi.ps1
./scripts/Start-QuietSelection.ps1
```

Для воспроизведения на другом ПК сначала согласуйте загрузку SDK и запустите `scripts/Install-ProjectSdk.ps1`. Проверяется SHA512 из официальных метаданных Microsoft. Скрипт не меняет системный PATH.

В разделе «Речь» выберите конкретный установленный голос для каждого языка и проверьте его кнопкой «Прослушать». В разделе «Сочетания клавиш» явно назначьте команды: по умолчанию они не зарегистрированы. Во время операции повтор любой команды останавливает её. Крестик, Alt+F4, локальные Ctrl+W/Ctrl+Q закрывают настройки; явное «Завершить» завершает приложение.

Мастер установки голосов предлагает RHVoice, отдельную подготовку моделей Piper, Silero, Kitten, Pocket, Kokoro и VOICEVOX и штатные компоненты Windows. Для SAPI может понадобиться отдельный установщик с повышенными правами; подготовка Piper и Silero выполняется от текущего пользователя. Загрузка и чтение разделены, сохранённый выбор голоса не меняется автоматически. Silero V5.6 Russian и V3 English бесплатны для некоммерческого использования по CC BY-NC-SA 4.0. См. [голоса и замеры ОЗУ](docs/voices.md) и [перевод](docs/translation.md).

## Структура

| Каталог | Назначение |
| --- | --- |
| `src/QuietSelection.Core` | Настройки, ограничения, планирование речи, отмена |
| `src/QuietSelection.App` | WPF, UI Automation, отдельные процессы, трей, рамка OCR |
| `src/QuietSelection.Native` | C++/WinRT для речи и OCR |
| `src/QuietSelection.Translation` | Изолированный локальный Python-процесс перевода |
| `src/QuietSelection.Speech` | Изолированные CPU-процессы Piper, Silero, Kokoro и VOICEVOX, звук небольшими порциями в памяти |
| `tests` | Проверки поведения на синтетических данных |
| `assets/fixtures` | Тестовые текст и локальная HTML-страница |
| `scripts` | Сборка, проверки и отдельные установщики |
| `packaging` | Манифест и стабильная идентичность MSIX |
| `docs` | Устройство, приватность, состояние и проверка |
| `.tools`, `artifacts` | Игнорируемые инструменты и результаты |
