До разрешения размер ZIP был получен через HTTP HEAD, распакованный размер — из центрального каталога ZIP. Тогда прочитаны только ограниченные диапазоны метаданных: последние 65536 байт, первые 6378 байт с README/LICENSE и 1178 байт конфигурации/описания предобработки. После разрешения загружен весь архив, включая возобновление проверенными HTTP-диапазонами. Его MD5 совпала с ETag объекта; это не цифровая подпись. Вычисленная SHA256: `ad601d0959cb408cf02e8c755c02b1dc0e67971ebac88c3b0c9645850617d0f3`. Она закреплена в загрузчике и каталоге приложения для контроля последующей неизменности.

Архив содержит веса `.npz` (309794437 байт), общий словарь `.yml` (1333938), отдельные `source.spm` (838812) и `target.spm` (1034727), а также документацию и вспомогательные файлы. Приложение использует разные токенизаторы для входа и выхода прямого маршрута; у моделей Argos сохранён общий токенизатор.

## Зависимости и преобразование

В изолированном runtime проекта уже имеются CPython 3.13.16, CTranslate2 4.8.3, SentencePiece 0.2.2, NumPy 2.5.4 и PyYAML 6.0.3. Преобразование `.npz`/`.yml` выполнено через [MarianConverter](https://opennmt.net/CTranslate2/python/ctranslate2.converters.MarianConverter.html), использующий NumPy и PyYAML. Результат — CTranslate2 int8 для выполнения на CPU.

PyTorch, Transformers, CUDA и отдельная установка Marian не потребовались. Нативные зависимости CTranslate2 работают с текущими моделями; Microsoft Visual C++ runtime присутствует на этом ПК. Чистая Windows без него отдельно не проверена. Совместимость конкретных весов подтверждена фактическим преобразованием и прямым переводом, в том числе при отсутствии обеих моделей составного маршрута.

В архиве предобработка описана Bash/sed/Perl-скриптом: замены пунктуации/полноширинных символов, удаление управляющих символов, нормализация пробелов и SentencePiece. Скрипты архива не исполняются. Нужные правила реализованы стандартной библиотекой Python без дополнительных пакетов. Ошибочное преобразование полноширинной цифры `１` в кавычку из исходного скрипта не перенесено: все цифры `０`–`９` преобразуются в `0`–`9`. Сохранение чисел и дат проверено отдельно. Постобработка выполняется уже имеющимся SentencePiece.

HTTP ETag не считается подписью или опубликованной SHA256. SHA256 вычислена после разрешённой загрузки и закреплена для контроля последующей неизменности; это локальная контрольная сумма, а не подпись издателя.
