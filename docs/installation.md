# Установка, идентичность и обновление

## Хранение результатов сборки (26 октября 2026)

В `artifacts/packages` сохраняется последний успешно установленный подписанный
MSIX (сейчас `QuietSelection_0.1.0.21_x64.msix`). Старые пакеты, включая
неподписанные копии, удалены по запросу пользователя; исторические записи ниже
описывают состояние на момент соответствующих обновлений.

`scripts/Build-Package.ps1` удаляет собственную временную папку упаковки в
`finally`, в том числе при ошибке, и удаляет незавершённый пакет. После успешной
сборки сохраняется только новый неподписанный пакет и предыдущие подписанные
пакеты. `scripts/Install-LocalPackage.ps1` удаляет остальные MSIX только после
успешной установки, оставляя подписанный пакет версии из `installation.json`.
Ошибка установки не удаляет предыдущий установщик. Прямой вызов Setup DLL
обходит эту очистку PowerShell-обёртки.

Очистка ограничена известными именами файлов и папками упаковки внутри проекта;
пути с junction/symlink отклоняются. Модели, SDK, исходники и данные приложения
не участвуют в очистке. Проверка на временных файлах:
`./tests/package_artifacts_test.ps1`.

## История установки

Установлен подписанный `artifacts/packages/QuietSelection_0.1.0.5_x64.msix` (121654195 байт). Предыдущие пакеты сохранены. Пакет включает приватные .NET 10.0.13 и Python 3.13.16 с библиотеками перевода. Launcher создаётся через `dotnet publish` и ищет .NET в `runtime` рядом с собой. Лицензии и notices включены. Модели хранятся отдельно в данных приложения и пережили обновление 0.1.0.4 → 0.1.0.5; готовность после обновления проверена реальным переводом. Прямая модель японский → русский добавлена из разрешённого локального архива без повторной загрузки прежних моделей.

Идентичность пакета: `QuietSelection.Windows`, издатель `CN=QuietSelection.Local`, ID приложения `App`, архитектура x64. Код исполняется на обычном пользовательском уровне. `runFullTrust` означает desktop-процесс вне AppContainer, а не права администратора.

Microsoft документирует требование идентичности пакета для Windows.Media.Ocr. Хотя на данном ПК синтетические OCR-вызовы сработали и без упаковки, это не считается гарантией поддерживаемого развёртывания. Поэтому производственная команда OCR проверяет идентичность до захвата экрана.

Для локального тестирования подготовлен C#-помощник `QuietSelection.Setup.dll`. Обёртка `scripts/Install-LocalPackage.ps1` вызывает его только с `-ConfirmLocalPublisherTrust`. Если исполнение скриптов запрещено, запускать DLL через локальный dotnet; политики PowerShell не изменять. Помощник:

1. Создаёт либо повторно использует сертификат `CN=QuietSelection.Local` в `CurrentUser\My`; закрытый ключ неэкспортируемый и не хранится в Git.
2. Добавляет открытый сертификат в `CurrentUser\TrustedPeople`; этого оказалось недостаточно для MSIX на данном ПК.
3. Подписывает копию пакета и передаёт её штатному Windows PackageManager.AddPackageAsync для проверки подписи и установки текущему пользователю.

Отдельная команда помощника `trust-machine-public <корень-репозитория> --confirm-machine-public-trust` проверяет `.tools/signing/QuietSelection.Local.cer`, его Subject и thumbprint, затем запускает системный certutil через UAC. Она добавляет **только публичную часть** в LocalMachine/TrustedPeople и проверяет отсутствие private key в машинной записи. 19 октября пользователь явно разрешил эту операцию; она выполнена. Закрытый ключ остаётся неэкспортируемым в CurrentUser/My, Root не используется. После этого PackageManager установил MSIX, что подтверждено `artifacts/packages/installation.json`.

Это локальная схема разработки, не публичная подпись и не обещание отсутствия запросов SmartScreen. Смена области доверия не выполняется автоматически из команды `install` и для другого ПК требует отдельного явного согласия.

Идентичность пакета, синтетические OCR/TTS и обе темы проверены после установки; полный сценарий рамки OCR и фокуса остаётся для приёмки. Автозапуск пока отключён в интерфейсе. После его реализации он будет включаться только явно и использовать устойчивую идентичность пакета.
