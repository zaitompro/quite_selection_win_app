# Локальный перевод

В установленной версии 0.1.0.5 используются CTranslate2 4.8.3 (CPU int8, два потока), SentencePiece 0.2.2 и изолированный CPython 3.13.16. Английский → русский: Argos 1.9. Японский → русский: прямая модель Helsinki-NLP / OPUS-MT. Скрытого перехода через английский нет. Японский → английский по-прежнему доступен через Argos 1.1, если английский выбран основным. Остальные направления показываются как неподдерживаемые.

Исходный архив прямой модели `jpn-rus/opus-2021-02-18.zip` загружен полностью: 288618087 байт. После преобразования рабочие файлы занимают 87083202 байта; дополнительные библиотеки не понадобились. Вложенная лицензия — CC BY 4.0. Метка Apache-2.0 в карточке [другой публикации на Hugging Face](https://huggingface.co/Helsinki-NLP/opus-mt-ja-ru) не заменяет лицензию выбранного архива. Источник, состав и контрольная сумма описаны в [предложении по прямой модели](direct-ja-ru-proposal.md).

## Подготовка

Исходный набор из семи архивов занимает 357540189 байт, дополнительный архив прямой модели — 288618087 байт. Все восемь находятся в `.tools/translation-downloads`, суммарно 646158276 байт. Python и wheels сверены с SHA256 издателей. SHA256 моделей рассчитаны после получения с официальных HTTPS-источников и закреплены в каталоге; это контроль неизменности, а не цифровая подпись издателя. Для прямого архива MD5 также совпала с ETag объекта.

Скрипт `Get-TranslationBundle.ps1 -ConfirmDownload` повторно использует уже проверенные архивы. `Prepare-TranslationRuntime.ps1` распаковывает изолированный runtime, не меняя системный Python, PATH и пользовательские site-пакеты. Runtime: 129677799 байт. Неиспользуемая GPU-библиотека cuDNN исключена; исходный wheel сохранён. На этом ПК уже присутствует необходимая Microsoft Visual C++ runtime (`MSVCP140.dll`); чистая машина без неё отдельно не проверена.

Runtime входит в MSIX. Модели устанавливаются отдельно в каталог данных текущего пользователя: `QuietSelection/models/argos-v1` внутри LocalApplicationData (Windows может перенаправлять данные пакетного приложения). Имя каталога сохранено для совместимости обновления. Используемые файлы всех трёх моделей занимают 437353475 байт. Извлекаются только разрешённые данные, токенизаторы и документация; Stanza и скрипты из архивов не выполняются. Подтверждённые хешами старые модели копируются в подготовленный набор, поэтому обновление не загружает их снова. Предыдущий набор сохраняется отдельно до и после успешной замены; резервные наборы занимают дополнительное место.

Прямой архив преобразуется `prepare_marian.py` через имеющийся MarianConverter. Его процессу запрещены сетевые сокеты и дочерние процессы; Windows Job ограничивает память 3 GiB. После преобразования проверяются закреплённые хеши всех итоговых файлов и реальный перевод для каждого из трёх направлений. Повторное преобразование внутри установленного MSIX дало те же файлы, что и разработческая подготовка. Для воспроизведения преобразования: `.tools/translation-runtime/python.exe -I -B scripts/prepare_direct_japanese.py`; скрипт работает только с уже скачанным архивом, сверяет исходные и итоговые файлы с каталогом.

В разделе «Перевод»: «Загрузить / восстановить модели…», «Проверить готовность», «Отменить подготовку». Полная загрузка моделей — 601520496 байт; при обновлении проверенного прежнего набора нужны только 288618087 байт новой модели. Индикатор считает полученные байты недостающих архивов. Ограничение отсутствия данных — три минуты на ожидание заголовков/чтение; общего короткого таймаута загрузки нет. Закрытие настроек оставляет подготовку в фоне; обычный выход отменяет её и ожидает завершения. Принудительное завершение Windows может оставить незавершённый каталог `preparing-*`; он не считается готовым набором.

## Работа

Команда перевода получает только выделение. Неопределённые фрагменты требуют отдельного выбора исходного языка на текущую операцию. Известные фрагменты и основной язык сохраняют свои назначения; настройка автоопределения обычной речи не влияет на перевод.

Все маршруты, целевой голос и целостность моделей проверяются до начала речи. Полный перевод подготавливается в памяти. Рабочий процесс получает ограниченный двоичный JSON через стандартные потоки, без текста в командной строке, файлах или диагностике. Python audit hook запрещает сетевые сокеты, запуск дочерних процессов и запись файлов. В inference нет загрузчика, HTTP-клиента или облачного fallback. Это не проверка всех нативных библиотек анализатором сетевого трафика.

Каждый процесс запускается заново, с CPU int8 и двумя вычислительными потоками. Windows Job завершает его при выходе родителя и ограничивает выделенную память 1,5 GiB. Модели загружаются последовательно. Отмена завершает процесс и ожидает его остановки. Общий срок одной операции — 10 минут, затем предлагается меньший фрагмент. Длинный текст разбивается без ограничения `max_input_length`, обрезающего вход; достижение предела декодирования считается ошибкой, а не успешным переводом.

## Проверки и качество

В установленном MSIX 0.1.0.5 прошли 17/17 проверок с подготовкой, затем 15/15 в новом процессе без подготовки. В кэше установочного теста был только прямой архив: это подтвердило повторное использование прежних двух моделей. Проверены целостность и отказ при повреждении, готовность реальным переводом, прямой японский перевод при полном отсутствии моделей составного маршрута, сохранение японский → английский, порядок смешанного текста, основной язык без моделей, отмена и перезапуск. Отчёт установки: `artifacts/test-results/translation-install-direct/translation.json`; повторного запуска: `artifacts/test-results/translation-installed/translation.json`.

На i5-8350U прямые короткие японские запросы с запуском отдельного процесса заняли около 1,0–1,2 секунды. Пиковая рабочая память в совокупности тестов английского и японского — около 438 МБ. Это не отдельное измерение RAM только японской модели. Разработческое сравнение `tests/translation_compare.py` на восьми фиксированных фразах показало 0,10–0,74 секунды для прямого маршрута в уже работающем процессе против 2,3–3,4 секунды для составного с загрузкой его стадий; эти условия отличаются от времени команды пользователя.

Дата `2027年3月3日`, включая вариант с полноширинными цифрами, перевелась как 3 марта 2027 года; число `１２３４５` сохранилось как 12345. Исправлена нормализация полноширинной цифры 1: исходный скрипт модели ошибочно заменял её кавычкой. Вход и выход используют разные исходные SentencePiece-модели.

Качество ограничено. Прямая модель перевела деловое приветствие `お世話になっております` как «Я о вас позабочусь», а `(水)` в короткой строке даты — как «(ввода)». Переход на прямую модель не означает, что все её переводы лучше составных. В прежнем составном маршруте тестовое письмо давало посторонний шаблон вместо приветствия. Английский `by Friday` ранее стал «в пятницу», потеряв оттенок крайнего срока. Функциональные зелёные тесты не являются полной семантической оценкой качества.
