## Локальные Microsoft Natural voices: исследование 19 октября 2026

Рассматривается только синтез на компьютере. Облачные голоса, сетевые адаптеры Edge и облачная подмена отсутствующего голоса исключены по требованию пользователя. [Microsoft подтверждает](https://support.microsoft.com/en-us/accessibility/windows/narrator/complete-guide-to-narrator), что загруженные Natural voices диктора работают без интернета. Однако публичный WinRT `SpeechSynthesizer.AllVoices` не обещает предоставлять именно эти пакеты сторонним приложениям. Запрос NVDA на их штатную поддержку [остаётся открытым с меткой blocked/needs-external-fix](https://github.com/nvaccess/nvda/issues/13288); новый запрос 2026 года закрыт как дубликат, а не как реализованная функция.

Техническая возможность стороннего локального использования существует: [NaturalVoiceSAPIAdapter](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter) предоставляет совместимые файлы Narrator через SAPI 5. Исходники v0.2.10 используют `EmbeddedSpeechConfig::FromPath` для локального пути. Название используемой библиотеки Speech SDK не означает облачный синтез в этом режиме. При этом автор описывает недокументированный доступ с извлечёнными ключами: это не поддерживаемый Microsoft API для повторного использования системных пакетов.

По [документации адаптера](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter/wiki/Narrator-natural-voice-download-links), новые Store-пакеты перестали работать после изменения ключей. Совместимые старые MSIX можно скачать и распаковать в отдельную папку; устанавливать сами голоса в Windows не требуется. Архивные пакеты размещены сторонним сообществом, а не текущим Microsoft Store. Стандартная установка самого адаптера требует регистрации SAPI COM-компонента с повышением прав. Прямое подключение без системной регистрации внутри QuietSelection пока не реализовано и не проверено.

Проверенные размеры HTTP HEAD (десятичные МБ; бинарные файлы не скачаны, подписи/хеши моделей не проверены):

| --- | --- | ---: | ---: |
| Адаптер v0.2.10, архив x86+x64 | Общий движок | 22 999 239 | 23,00 |
| Aria v2, пакет 1.0.1.0 | Английский США / женский | 16 091 255 | 16,09 |

Версия и размер адаптера проверены по [GitHub release v0.2.10 от 14 октября 2026](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter/releases/tag/v0.2.10); размеры голосов — по ссылкам из wiki автора. Это объём загрузки, а не расход ОЗУ. RAM, задержка, совместимость с нашим MSIX и автономность сетевого поведения не измерены. На этом ПК запрос текущего пользователя `Get-AppxPackage -Name 'MicrosoftWindows.Voice.*'` не вернул установленных пакетов.

В [официальном списке Natural voices](https://support.microsoft.com/en-us/accessibility/windows/narrator/appendix-a-supported-languages-and-voices) есть английский и японский, но нет русского. [Автор адаптера подтверждает это для Windows 11 25H2](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter/issues/101) и отличает неофициально распространяемые русские данные от пакетов Narrator. Публикации о драйвере NeuralVoices и русских голосах в сообществах NVDA не подтверждают разрешение Microsoft на распространение самих моделей. MIT-лицензия кода адаптера также не заменяет условия голосовых данных.

Возможная будущая проверка требует отдельного согласования загрузки/установки: закрепить версии и подписи пакетов, использовать только локальный источник, отключить сетевые источники и журналирование адаптера до первого вызова. У адаптера сетевой источник Edge включён по умолчанию; [настройки](https://github.com/gexgd0419/NaturalVoiceSAPIAdapter/wiki/Configurable-registry-values) позволяют его отключить и выключить журналы. Это план проверки, не утверждение о выполненном аудите. Голоса/адаптер не установлены, системные настройки и текущий английский Piper не изменены.

В «Речь → Установка голосов…» доступны бесплатные RHVoice Elena (русский, 8 228 573 байта) и SLT (английский, 7 714 064 байта). Оба пакета включают движок SAPI 5 и установлены на этом ПК. Их версии, официальные ссылки и опубликованные GitHub SHA-256 закреплены в `src/QuietSelection.App/Speech/Downloads/rhvoice.json`. Доступны прогресс, отмена загрузки и повторное использование проверенного кэша; при чтении сеть не используется. Установщики не имеют Authenticode-подписи: перед запуском проверяются точные размер и SHA-256. Штатный запрос UAC относится только к установщику, не к приложению. Закрытый ключ QuietSelection не используется для переподписания чужих пакетов.

Японского RHVoice нет в [официальном списке языков](https://rhvoice.org/languages/). Существующие японские голоса Windows сохранены. После установки выберите конкретный голос в разделе «Речь» и нажмите «Прослушать»: сохранённые настройки автоматически не меняются.

Условия: [Elena — GPL v3](https://github.com/RHVoice/elena-rus), [SLT — CMU license](https://github.com/RHVoice/slt-eng); лицензия движка описана [у RHVoice](https://github.com/RHVoice/RHVoice/blob/master/doc/en/License.md). Установщики скачиваются с официальных релизов отдельным действием и не включены в MSIX. Первичные копии находятся в `.tools/voice-downloads`; пользовательская загрузка из интерфейса — в данных QuietSelection, `downloads/rhvoice`.

Дополнительно сохранены два пути установки голосов Microsoft:

1. Помощник QuietSelection: пользователь явно выбирает русский или английский, читает подтверждение, затем подтверждает UAC для каждого из двух компонентов. Приложение запускает системный `dism.exe` с фиксированными аргументами и языком из белого списка. Через настроенный Windows источник компонентов устанавливаются `Language.Basic~~~ru-RU~0.0.1.0` и `Language.TextToSpeech~~~ru-RU~0.0.1.0` либо соответствующие `en-US` компоненты. Политика PowerShell, язык интерфейса, раскладки, Narrator и другие средства доступности не меняются. Установка ожидается без произвольного короткого таймаута. Код 3010 означает необходимость перезагрузки, автоматический рестарт запрещён параметром `/NoRestart`. Точный объём загрузки на этом ПК ещё не установлен. Закрытие приложения не отменяет уже начатое обслуживание Windows.
2. Кнопка перехода в штатный раздел речи Windows (`ms-settings:speech`) и короткая инструкция, если автоматическое обслуживание запрещено политиками или нет прав администратора.

После окончания помощника QuietSelection заново перечисляет голоса и синтезирует фиксированную тестовую фразу. Сообщение об успешной установке компонента само по себе не означает готовность речи. Затем пользователь выбирает голос в списке и прослушивает его. Сохранённые привязки не подменяются автоматически.

**Статус на 19 октября:** ru-RU и en-US завершены DISM с кодом 0. Установленный MSIX успешно синтезировал русскую тестовую фразу при скоростях 0/50/100 (390926/196366/33326 байт WAV), английскую — 363566/181806/35144 байта. Звук оставался в памяти, файлы аудио не сохранялись. Перезапуск Windows не выполнялся.

## Более естественные голоса Microsoft

Системный WinRT backend использует голоса, которые реально перечисляет `Windows.Media.SpeechSynthesis.SpeechSynthesizer.AllVoices`, с отдельной проверкой синтеза. Он не объявляет их нейросетевыми или Natural по имени языка. SAPI, Piper и Silero подключены отдельными backend.

Microsoft предлагает Natural Voices для Narrator: английские Jenny, Aria, Guy, японские Nanami и Keita. В опубликованном списке Natural Voices русский отсутствует; обычные русские системные голоса перечислены отдельно. После загрузки Natural Voices работают локально в Narrator. Источники: [список голосов](https://support.microsoft.com/en-us/accessibility/windows/narrator/appendix-a-supported-languages-and-voices), [руководство Narrator](https://support.microsoft.com/en-us/accessibility/windows/narrator/complete-guide-to-narrator). Их доступность из QuietSelection через используемый WinRT API пока не подтверждена; установка для Narrator сама по себе не считается подтверждением.

[Azure Speech](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/language-support?tabs=tts) предлагает нейросетевые голоса, включая русский. Обычный облачный API передаёт текст сервису и не используется в этом проекте. [Embedded Speech](https://learn.microsoft.com/en-us/azure/ai-services/speech-service/embedded-speech) поддерживает локальный нейросинтез, но требует отдельного одобрения Microsoft, моделей и Speech SDK. У него отдельные зависимости и условия; это не готовая замена системному движку без исследования. Эти компоненты и Natural Voices сейчас не загружались.

Если голоса устанавливались отдельным помощником при уже открытом приложении, нажмите «Речь → Обновить список голосов». Выберите конкретный голос для каждого языка и нажмите «Прослушать». Установка сама по себе не подменяет сохранённый выбор голоса.

### SAPI и текущая реализация

SAPI 5 — интерфейс Windows для работы с речевыми движками, в том числе сторонними; качество определяется самим движком и голосом. Реализованы два пути: прежний WinRT `Windows.Media.SpeechSynthesis` и новый `SapiSpeech.cpp` с `ISpVoice`. SAPI-голоса сохраняются с префиксом `sapi5:` и точным ID токена; прежние WinRT ID остаются совместимыми с версией настроек 1. Имя голоса показывает поставщика RHVoice и API. Отсутствующий ID вызывает ошибку, без выбора похожего голоса. Скорость SAPI отображается на диапазон −10…10 (шаг UI 5); WinRT сохраняет прежний диапазон 0,5…6,0. Источники: [SAPI overview](https://learn.microsoft.com/en-us/previous-versions/windows/desktop/ms720151(v=vs.85)), [WinRT SpeechSynthesizer](https://learn.microsoft.com/en-us/uwp/api/windows.media.speechsynthesis.speechsynthesizer).

SAPI получает только обычный текст (`SPF_IS_NOT_XML`) и ограниченный 128 МиБ поток PCM в памяти. WAV формируется в памяти, воспроизводится рабочим процессом и освобождается. Отмена завершает рабочий процесс вместе с синтезом или воспроизведением. Файлы пользовательского аудио не создаются. В отдельном процессе удерживается один выбранный движок; это также освобождает память голоса после чтения.

NVDA поддерживает несколько интерфейсов синтеза. Acapela для NVDA поставляется дополнением, управляемым из NVDA; это не универсальный пакет для нашего приложения. Отдельный Windows SDK Acapela предлагает SAPI5 и собственный API, но имеет коммерческую модель лицензирования, поэтому исключён из дальнейшего отбора. Похожее звучание на macOS само по себе не устанавливает происхождение голоса. Источники: [NVDA User Guide](https://api.nvaccess.org/documentation/userGuide.html), [Acapela для NVDA](https://www.acapela-nvda.com/), [Acapela Windows SDK](https://www.acapela-group.com/solutions/acapela-tts-for-windows/).

Длинный текст делится на предложения, отмена не ждёт окончания абзаца. Новый режим по умолчанию сохраняет до двух выбранных моделей между чтениями; выключение «Держать выбранные голоса Piper в памяти» возвращает запуск отдельного процесса для каждого запроса. Обновление ОЗУ на основании одних размеров моделей не требуется.

### Интеграция и дальнейшая оценка

Перечисление голосов, синтез, скорость и отмена работают через общий интерфейс рабочих процессов для WinRT, SAPI и Piper. Нейросетевые модели подключаются напрямую; поддержка SAPI не обязательна для Piper, Silero, Kokoro или VOICEVOX.

Настройки хранят точный ID голоса для каждого языка, сохраняя прежние WinRT-привязки. Префиксы `sapi5:` и `piper:` определяют дополнительные движки. Отсутствующий голос не подменяется автоматически. Текст передаётся только через память/IPC, синтез локальный, аудиофайлы и журналы текста не создаются. Piper выдаёт звук небольшими порциями; начальная задержка, отмена и память проверены на CPU этого ПК.

В интерфейсе предлагается каталог «Язык → Голос → Прослушать → Скачать», размер всей загрузки и установки, прогресс, отмена, удаление и повторное использование уже загруженного движка. Прослушивание до установки может использовать отдельно согласованный фиксированный образец; произвольный текст не отправляется сервисам. Автоматических загрузок при чтении нет. Для SAPI установка может требовать штатный установщик, поэтому обещать одинаковую установку одним щелчком для всех движков нельзя.

Первая сравнительная группа: русский Piper/Silero, английский Piper/Kokoro, японский VOICEVOX/Kokoro. RHVoice нужен только как запасной и возможный контрольный вариант. Для каждой пары — одинаковые синтетические предложения, даты и числа, аббревиатуры, короткие команды и длинные абзацы; обычная и повышенная скорость. Оценки: точность прочтения, естественность и утомляемость при прослушивании, задержка первого звука, RTF, пиковая RAM, отмена, повторный запуск и работа без сетевых обращений. Победителя по качеству определяет прослушивание пользователя, а не только название технологии.

Один запуск не изолирует влияние упаковки, нагрузки, антивируса и файлового кэша, поэтому не следует приписывать разницу только MSIX.

Максимум на длинной медленной фразе заметно выше, чем на длинном тексте из коротких предложений. Фиксированного гарантированного предела физической памяти эти тесты не устанавливают. Процесс имеет отдельный лимит **1 ГиБ private commit**, который нельзя назвать лимитом ОЗУ. В измеренном здесь режиме версии 0.1.0.8 процесс завершался после чтения и отмены. Это поведение сохраняется в 0.1.0.10 только при выключенном удержании моделей.

Проверены три скорости, полный проход длинного текста, отмена и повторный запуск, отсутствие подмены неизвестного ID, отказ до inference при повреждении весов, повреждение конфигурации того же размера, сохранение готового набора при отмене подготовки, фактическое воспроизведение русской и английской фраз и сетевое получение двух конфигураций. Отчёт: `artifacts/test-results/piper-installed/piper.json`. Успешный вызов воспроизведения не является пользовательской оценкой естественности: сравнение звучания выполняется кнопкой «Прослушать».

Воспроизведение для разработчика после отдельного согласия на загрузку:

```powershell
./scripts/Get-PiperBundle.ps1
./scripts/Prepare-PiperRuntime.ps1
./scripts/Build.ps1 -SkipNative  # если C++ уже собран
./scripts/Test-Piper.ps1 -PrepareFromApprovedCache
./scripts/Test-Piper.ps1 -Installed -PrepareFromApprovedCache -PlayTest -TestDownload
./scripts/Test-Piper.ps1 -Resident -Installed -PrepareFromApprovedCache -PlayTest
```

`-TestDownload` дополнительно проверяет сетевой загрузчик на небольших закреплённых конфигурациях. `-Resident` измеряет холодный запуск, пять повторных чтений, память в ожидании, длинный медленный текст, два голоса вместе и отмену с сохранением PID; проверяет выгрузку и обе темы интерфейса. Большие модели при проверке берутся из ранее разрешённого кэша. `tests/speech_guards.py` проверяет сохранение всех символов при разбиении длинного текста и запрет сокета/записи файла. Отчёты содержат только синтетические размеры, время и счётчики памяти, без текста пользователя и аудиозаписей. Лицензии runtime и ссылки на карточки моделей: `third-party/piper/NOTICE.md`.
